# ProjectSansa Terminology 参照方針

## 1. 概要

ProjectSansa 側で、ecosystem-wide shared terminology authority を管理する方向が整理されている。

SansaSphere は terminology consumer として、ProjectSansa shared terminology を参照する方向を推奨する。

---

## 2. 参照対象

### governance / provenance

- governance
- provenance
- provenance chain
- provenance graph
- restriction
- ownership
- verification
- trust
- policy

### ecosystem architecture

- local-first
- offline-first
- creator-first
- optional ecosystem integration
- provenance ecosystem
- governance ecosystem
- trust ecosystem
- detection ecosystem

---

## 3. SansaSphere 側 responsibility

SansaSphere 側では、repository-specific extension のみ定義する方向を推奨する。

### examples

- federation trust
- distributed verification
- signed audit event
- distributed timestamp
- misuse detection ecosystem

---

## 4. important policy

shared concepts 自体は ProjectSansa terminology authority を参照する。

SansaSphere 側では ecosystem-specific trust / verification extension を扱う。
