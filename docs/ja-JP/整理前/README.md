# 整理前

## 概要

このフォルダは、SansaSphere の責務整理前に存在していた資料を保管する領域である。

整理前資料は、削除対象ではなく、以下の目的で一時的に保全する。

- 旧構成の保全
- SansaSphere 責務への再分類
- Project Sansa 全体資料との切り分け
- 将来的な別リポジトリ移管判断
- 整理作業の根拠確認

## 現在の整理方針

SansaSphere は、Project Sansa ecosystem における共通バックエンド基盤サービスを扱う。

残す方向で整理する主な領域は以下である。

- ユーザー認証
- セッション管理
- アカウント管理
- Webサービス基盤
- サーバー基盤
- 共通バックエンド機能
- Federation / Identity
- ログ・監査
- API基盤
- テスト基盤
- VN3 license 管理
- governance / provenance 管理

SansaSphere の主責務ではない可能性がある領域は、整理後に Project Sansa 全体または別リポジトリへ移管する。

## 移管・保留候補

以下は、SansaSphere 単体責務ではなく、Project Sansa 全体または XR / Runtime 系責務を含む可能性があるため、整理対象として扱う。

- o3de
- ロゴマーク
- 仕様/00_全体構想
